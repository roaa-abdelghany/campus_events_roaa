# CampusEvents — SW302 HTML/CSS Project

## Files
- `index.html` — home page
- `events.html` — event listing
- `event-details.html` — featured event, HTML video/audio, review form
- `schedule.html` — accessible schedule tables
- `registration.html` — registration form with native HTML validation
- `style.css` — shared responsive stylesheet and CSS-only dark mode
- `assets/` — three event images, a short MP4 preview, and a WAV audio intro

## Run it
1. Keep the folder structure unchanged.
2. Open `index.html` in Chrome.
3. Use the navigation links to move between pages.
4. Click “Dark mode” on any page. This uses a CSS-only checkbox and does not require JavaScript.

## Assets included
- `innovation-day.jpg`: illustrated auditorium / innovation event scene
- `coding-workshop.jpg`: illustrated computer lab / coding scene
- `sports-day.jpg`: illustrated outdoor sports scene
- `event-preview.mp4`: short slideshow-style event preview made from the included images
- `event-intro.wav`: short, original musical chime intro (not spoken narration)

The images are original illustrated assets for this class-project demo, not real photographs of your university. If your instructor expects real photos, replace the JPGs with your own campus/event photos and keep the same filenames.

## Important note
The forms demonstrate HTML validation in the browser only. They do not store or send registrations or reviews because a server/backend is not part of this HTML/CSS-only project.
